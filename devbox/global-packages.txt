# devbox global で管理するパッケージ一覧（dotfiles 管理）
#
# 反映:
#   bash ./scripts/devbox-global-sync.sh
#
# ルール:
# - 1 行 1 パッケージ
# - 空行/先頭 # はコメント扱い
#
# 全マシン共通の宣言。sync スクリプトは「宣言にあって入っていないものを add する」
# だけで、宣言に無いものは STRICT=1 APPLY_REMOVE=1 を付けない限り削除しない。
# そのため、あるマシンに不要なパッケージが混ざっていても壊れないが、
# sync を素で流すと宣言分すべてが入る（qemu は nix の closure が大きい）。
